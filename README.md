# Happy Girlfriend’s Day, Muskan ♡

A polished Punjabi-English Girlfriend’s Day website made by Love for Muskan.

## Add your chosen song
1. Choose an MP3.
2. Rename it to `our-song.mp3`.
3. Put it inside the `assets` folder.

## Preview in Visual Studio Code
Open the folder in VS Code and run `index.html` using the Live Server extension.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload every file from this folder, keeping the `assets` folder intact.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then choose **main** and **/(root)**.
5. Save and wait for the public link.

The design is responsive and works best on mobile as well as desktop.
